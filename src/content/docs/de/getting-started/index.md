In drei Schritten vom koreanischen Shop bis zu Ihrer Haustür.

1. **Erstellen Sie Ihr Konto.** Sie erhalten einen persönlichen Postbox code (Postfach-Code), zum Beispiel `KF2331`, und unsere Lageradresse in Incheon. Bei der Registrierung erhalten Sie einen Welcome Coupon über ₩5,000.
2. **Bringen Sie Ihre Artikel in unser Lager.** Wir kaufen sie mit Buy For Me für Sie, oder Sie kaufen selbst ein und schicken sie mit Receive For Me an uns.
3. **Versenden Sie sie nach Hause.** Fassen Sie alles in einem Karton zusammen, wählen Sie einen Versanddienstleister und bezahlen Sie.

## Ihr Postbox code

Über Ihren Postbox code ordnen wir ein Paket Ihnen zu. Er besteht aus zwei Buchstaben und vier Ziffern, zum Beispiel `KF2331`. Er erscheint sofort nach der Registrierung in Ihrem Dashboard und ändert sich nie.

> Geben Sie immer Ihren Postbox code an, wenn Sie etwas an unser Lager schicken.

## Ihre koreanische Adresse

Verwenden Sie sie genau so, wie sie hier steht, wenn ein koreanischer Shop nach der Lieferadresse fragt. Tragen Sie **Ihren eigenen Namen** als Empfänger ein, nicht "KoreaHaul".

```text
Recipient: [Ihr Name]
인천광역시 부평구 부평북로 58, 2층 201호 [Ihr Postbox code]
58, Bupyeongbuk-ro, Bupyeong-gu, Incheon
2F, Suite # 201 [Ihr Postbox code]
Postal code 21302
Republic of Korea
Phone: 010-5725-1222
```

Koreanische Bestellformulare verlangen meist die koreanischen Zeilen.

- **Adresssuche (주소 찾기):** Suchen Sie nach `인천광역시 부평구 부평북로 58`. Das Formular trägt die Postleitzahl (우편번호) automatisch ein.
- **Adresszeile 2 (상세주소):** `2층 201호 [Ihr Postbox code]`

> Ohne Postbox code können wir Ihr Paket nicht Ihrem Konto zuordnen, was zu Verzögerungen führt. Wir verwahren es als nicht zugeordnetes Paket und führen es auf unserer [Notice-Seite](https://koreahaul.com/support/notice) auf. Schauen Sie dort nach und beanspruchen Sie es.

## Was passiert, wenn Ihr Paket ankommt

- Wir checken es in der Regel 1-2 Tage nach dem Eingang im Lager ein.
- Wir erstellen Unboxing-Medien und laden sie in Ihr Dashboard hoch, damit Sie sie prüfen können.
- Es erscheint mit seinem Check-in-Datum in Ihrer Lagerliste.
- Ihre 45 kostenlosen Lagertage beginnen mit diesem Check-in-Datum.

Für Artikel, die an verschiedenen Tagen eingecheckt werden, läuft jeweils eine eigene Frist.

## Bereit für den Versand

- Fordern Sie einen Versand über [Ship For Me](https://koreahaul.com/account/ship-for-me) an.
- Wir verpacken, wiegen und vermessen den Karton.
- Wählen Sie einen Versanddienstleister anhand der tatsächlichen Preise, die wir Ihnen nennen.
- Nutzen Sie den Shipping Calculator (Versandkostenrechner) auf [KoreaHaul](https://koreahaul.com/), um die Kosten vor Ihrer Anfrage zu schätzen.
