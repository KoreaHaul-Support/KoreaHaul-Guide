Unser Bunjang-System wird gerade gewartet. Ab **Montag, 12. Oktober 2026** läuft wieder alles normal.

## So kaufen Sie in der Zwischenzeit bei Bunjang

- Senden Sie Ihre Kaufanfrage für Bunjang über das [individuelle Formular für Buy For Me](https://koreahaul.com/services/buy-for-me/create).
- Fügen Sie den Link zum Bunjang-Angebot ein und ergänzen Sie bei Bedarf Hinweise für uns.

Wir aktualisieren diesen Hinweis, sobald das System wieder verfügbar ist. Vielen Dank für Ihre Geduld. Fragen? Schreiben Sie an [support@koreahaul.com](mailto:support@koreahaul.com).
