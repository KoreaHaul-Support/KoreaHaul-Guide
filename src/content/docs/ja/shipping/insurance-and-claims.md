荷物が紛失または破損した場合に補償される内容と、その際の対応についてご説明します。

## 標準で付いている補償

どのサービスにも、配送業者が提供する補償が付いています。これは保険とは異なり、内容もサービスによって大きく違います。

| サービス | 紛失 | 輸送中の破損 |
| --- | --- | --- |
| FedEx | 標準でUSD $100（約KRW 135,000）まで | 標準でUSD $100（約KRW 135,000）まで |
| EMS Korea Post | 配送業者の規定による | 補償なし |
| SF Express | 配送業者の規定による | 補償なし |
| International Standard Shipping | 配送先によって異なる（下記参照） | 補償なし |

**International Standard Shippingの配送先別の紛失補償**

| 配送先 | 補償額の上限 |
| --- | --- |
| アメリカ | USD $200（約KRW 270,000） |
| 欧州連合（EU） | USD $155（約KRW 209,000） |
| 日本、中国、香港 | USD $40（約KRW 54,000） |
| メキシコ、イスラエル、サウジアラビア、トルコ | 補償なし |
| その他すべての地域 | USD $50（約KRW 67,500） |

KRWの金額は目安で、為替レートによって変動します。

4つのサービスのうち3つは、輸送中の破損を補償しません。壊れやすい商品をお送りになる場合、このページで最も重要なポイントです。

## 任意のShipping Insurance（配送保険）

- **FedExのみ。** その他のサービスではご利用いただけません。
- **申告額の2%**で、発送をリクエストするときに選択します。
- 保険会社の規約に従い、輸送中の紛失や破損を補償します。

補償の対象や、補償金が支払われるかどうかは、配送業者または保険会社が決定します。当社は保険会社ではなく、その決定は行いません。

## 発送前にリスクを下げる

- **Extra Protection、1点あたり₩3,000。** エアキャップと緩衝材を追加します。陶器、ガラス、タンブラー、未開封のブースターボックス、写真集におすすめです。
- **Optimized Pack、₩2,000 + 荷物1個あたり₩1,000。** 中身が動いて壊れる原因になる、箱の中の余分なすき間をなくします。元の配送箱は取り外す場合がありますが、密封された商品パッケージは取り外しません。
- 中身が大切な場合は、破損を補償するサービスをお選びください。

## 問題が起きた場合

1. 箱と梱包材は捨てずに保管してください。これらがないと補償請求は通りません。
2. 外箱、内側の梱包材、破損した商品の写真を撮ってください。
3. リクエスト番号、動画、写真を添えて [support@koreahaul.com](mailto:support@koreahaul.com) までご連絡ください。
4. 配送業者が必要とする発送記録と書類を、当社がご用意します。

補償請求は配送業者または保険会社に対して行い、その判断も配送業者または保険会社が行います。当社は補償請求をサポートしますが、補償金の支払いは行いません。

破損は、国際配送のお届けから**14日以内**にご報告ください。配送業者は期限を過ぎた補償請求を受け付けず、期限を過ぎると当社でも対応できません。

</div>

## 荷物の紛失

- 5営業日以上動きがない場合は、リクエスト番号をお送りください。当社で調査を開始します。
- 調査には時間がかかります。通常、配送業者は自社の調査が終わるまで、荷物を紛失扱いにしません。
