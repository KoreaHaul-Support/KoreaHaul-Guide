韓国のショップからお手元まで、3つのステップで届きます。

1. **アカウントを作成します。** 専用のPostbox code（私書箱コード、例: `KF2331`）と、仁川にある当社倉庫の住所が発行されます。ご登録時に₩5,000のWelcome Couponも発行されます。
2. **商品を当社倉庫に届けます。** Buy For Meで当社が代わりに購入するか、ご自身で購入してReceive For Meで当社宛てに発送してください。
3. **ご自宅へ発送します。** すべてを1つの箱にまとめ、配送業者を選んでお支払いください。

## Postbox code について

Postbox codeは、荷物とお客様を照合するためのコードです。英字2文字と数字4桁の組み合わせで、`KF2331` のような形式です。ご登録と同時にダッシュボードに表示され、変更されることはありません。

> 当社倉庫に何かを送るときは、必ずPostbox codeを記入してください。

## 韓国の住所

韓国のショップで配送先を聞かれたら、下記のとおり正確に入力してください。受取人には「KoreaHaul」ではなく、**ご自身のお名前**を入力してください。

```text
受取人: [お客様のお名前]
인천광역시 부평구 부평북로 58, 2층 201호 [お客様のPostbox code]
58, Bupyeongbuk-ro, Bupyeong-gu, Incheon
2F, Suite # 201 [お客様のPostbox code]
郵便番号 21302
Republic of Korea
電話番号: 010-5725-1222
```

韓国のショップの購入フォームでは、通常は韓国語の行を入力します。

- **住所検索（주소 찾기）:** `인천광역시 부평구 부평북로 58` で検索してください。郵便番号（우편번호）は自動で入力されます。
- **詳細住所（상세주소）:** `2층 201호 [お客様のPostbox code]`

> Postbox codeがないと、荷物をお客様のアカウントと照合できず、遅延の原因になります。その場合は持ち主不明の荷物として保管し、[お知らせページ](https://koreahaul.com/support/notice)に掲載します。そちらを確認して所有を申請してください。

## 荷物の到着後の流れ

- 通常、倉庫に到着してから1-2日で入庫手続きを行います。
- 開封写真・動画を記録し、ダッシュボードにアップロードしますので、ご確認ください。
- 荷物は入庫日とともに倉庫リストに表示されます。
- 45日間の無料保管期間は、その入庫日から始まります。

別々の日に入庫した商品は、それぞれ個別にカウントされます。

## 発送の準備ができたら

- [Ship For Me](https://koreahaul.com/account/ship-for-me)から発送をリクエストします。
- 当社が箱を梱包し、重さとサイズを測ります。
- 提示する実際の料金を見て、配送業者を選びます。
- リクエストの前に、[KoreaHaul](https://koreahaul.com/)のShipping Calculatorで費用の目安を確認できます。
