料金はすべて韓国ウォン（KRW）で表示しています。

お支払いは2回です：1回目は購入代金、2回目は国際送料です。以下の項目を合計すると、ショップからお手元に届くまでのご注文の費用を見積もれます。

## ステップ1: 購入の請求書（Buy For Me）

| 項目 | 加算する金額 |
| --- | --- |
| 商品価格 | 韓国のショップでの価格です。 |
| 韓国国内送料 | ショップが当社倉庫までの配送に請求する送料です。一定金額以上で無料になることがよくあります。 |
| Buy For Me サービス料 | 商品ラインごとにBasic ₩2,000またはStandard ₩5,000。Premiumは1点あたり ₩30,000。 |

Receive For Meをご利用の場合は、商品をご自身で購入されるため、このステップは不要です。

## ステップ2: 発送の請求書（Ship For Me）

### 1. 請求重量を確認する

配送業者は、次のうち重い方で料金を計算します。

- **実重量** - はかりで量った荷物の重さ。
- **容積重量** - L × W × H (cm) ÷ 5000。

たとえば、40 × 30 × 25 cmで重さ3 kgの箱は容積重量が6 kgになるため、6 kg分の料金がかかります。

### 2. 送料を確認する

[KoreaHaul](https://koreahaul.com/)の送料計算ツール（Shipping Calculator）に、お住まいの国と請求重量を入力してください。遠隔地の追加料金は、該当する場合に後から加算されます。配送業者の比較は[配送業者と送料](/shipping/carriers-and-rates/)をご覧ください。

### 3. ご希望のオプションを加える

| オプション | 料金 |
| --- | --- |
| Inclusions Basic / Inclusions Premium（同梱物ベーシック / プレミアム） | ₩1,000 / ₩2,000 / 点 |
| Extra Protection（追加保護） | ₩3,000 / 点 |
| Vacuum Packing（真空パック） | ₩6,000 / 点 |
| Optimized Pack（最適化梱包） | ₩2,000 + 荷物1個あたり ₩1,000 |
| Priority Pack（優先梱包） | ₩5,000 / 発送 |
| Package Split（荷物の分割） | 分割後の荷物1個あたり ₩5,000 |
| Adult Signature Required（成人の署名） | ₩6,000 |
| Shipping Insurance（配送保険） | 申告価格の2% |

オプションはすべて任意です。各オプションの内容は[料金](/getting-started/fees/)をご覧ください。

### 4. 必要に応じて保管料を加える

最初の45日間は無料です。その後は荷物1個につき1日₩1,000、容積重量が10 kg以上の場合は1日₩2,000です。保管料は発送の請求書にAdditional Chargeとして記載されます。

### 5. 輸入費用を加える

- **DDP:** 関税、税金、通関手数料をお支払い時にお支払いいただきます。通関手数料は、International Standard Shippingでは₩2,000～₩5,000です。FedEx International Connect Plusでは₩6,000、推定輸入費用が₩120,000を超える場合は₩12,000です。
- **DAP:** 荷物の到着時に、関税、税金、通関手数料を配送業者にお支払いいただきます。

関税は、お住まいの国の免税基準額、申告価格、HSコードによって決まります。[関税・税金の計算](/shipping/duty-and-tax-calculation/)と、[国別ガイド](/country-guide/)のお住まいの国のページをご覧ください。

## ステップ3: 決済手数料

どちらの請求書でも、お支払い時に決済手数料が加算されます。手数料はお支払い方法によって異なります。通常、Wiseの手数料が最も安くなります。[お支払い方法](/getting-started/payment-methods/)をご覧ください。

お支払い方法によっては上限が設けられている場合があります。

## 計算例

₩22,000の異なるアルバム2枚、Basic Proxy、FedEx International Connect PlusのDDPで発送する場合です。箱は30 × 25 × 10 cm、重さは1.2 kgなので、請求重量は1.5 kgになります。

| 項目 | 金額 |
| --- | --- |
| 商品（2 × ₩22,000） | ₩44,000 |
| 韓国国内送料 | ₩3,000 |
| Buy For Me サービス料（Basic、ローンチキャンペーン） | ₩0 |
| **購入の請求書** | **₩47,000** + 決済手数料 |
| 送料 1.5 kg（料金の例） | ₩30,000 |
| Inclusions Basic（2点） | ₩2,000 |
| DDP通関手数料 | ₩6,000 |
| 関税・税金 | お住まいの国によって異なります |
| **発送の請求書** | **₩38,000** + 関税、税金、決済手数料 |

この例の送料は説明のためのものです。実際の送料は送料計算ツールでご確認ください。

## 実際のお見積もり

商品が当社倉庫に届いたら、重さとサイズを測り、ご利用いただけるすべての配送業者を並べて比較したお見積もりをお送りします。送料のお見積もりの有効期限は**5日間**です。

## 費用を抑えるコツ

- すべての商品をまとめて1回で発送しましょう。
- Optimized PackやVacuum Packingで容積重量を減らしましょう。
- 45日間の無料保管期間が終わる前に発送しましょう。
- 利用できる場合はWiseでお支払いください。

その他のコツは[送料を節約する方法](/shopping-tips/how-to-spend-less-on-shipping/)をご覧ください。
