## 配送方式

- **SF Express** - 进口费用由收件人支付（DAP）。预计 4-7 个工作日。
- **FedEx International Priority** - 进口费用由收件人支付（DAP）。预计 2-4 个工作日。
- **EMS** - 进口费用由收件人支付（DAP）。不接受任何类型的电池，包括内置电池。预计 5-10 个工作日。

## 海关、关税与税费

<div class="kh-callout kh-callout--caution">

**清关由您自行负责。** 申请我们的服务前，请先确认您的商品可以进口到您所在的国家/地区。我们会按您的要求寄送，但无法保证商品能够顺利清关。

</div>

- **免税门槛（PHP 10,000 FOB/FCA）：**
    - FOB 或 FCA 价值在 PHP 10,000（约 US$180）及以下的商品，一般免征菲律宾关税和进口税。
    - FOB/FCA 一般指未计入国际运费和保险的商品价值。
    - 这是一个门槛判断，而不是从较大货件中扣除的免税额度。如果 FOB/FCA 价值超过 PHP 10,000，则可能对该进口货件核征关税和 VAT。
    - 即使价值在 PHP 10,000 以内，酒类和烟草仍可能需缴纳消费税。受限或受监管商品可能需要许可证或满足其他要求。
- **超过 PHP 10,000：** 可能需缴纳进口关税和 12% 的 VAT。关税取决于税则归类、完税价格、原产地和适用规则。
- **进口 VAT：** 按到岸总成本的 12% 计算；VAT 计税基数一般包括完税价格/应税价值，加上关税、适用的消费税以及放行前的相关费用。
- **完税价格：** 需缴纳关税和 VAT 时，海关一般按货件的应税价值或到岸价值（商品、国际运费、保险及适用的加计项目）进行核定。

## 费用估算

示例：商品价值 US$100，另加 US$30 国际运费。

- **免税门槛判断：** PHP 10,000 的门槛适用于 FOB/FCA 商品价值，不含国际运费和保险。折算成比索的结果取决于海关汇率。
- **如果商品价值不超过 PHP 10,000（且货件符合条件）：**
    - 关税和 VAT：一般无需缴纳
    - 您仍可能需要支付承运商费、处理费或派送费
- **如果商品价值超过 PHP 10,000：**
    - 完税价格/应税价值一般包括商品、运费、保险及适用的加计项目
    - 关税：取决于税则归类
    - 12% 的 VAT：按到岸总成本计算，包括适用的关税

*仅供参考。最终核定结果由菲律宾海关和承运商确定。*

## 无法寄送的物品

- 易燃品和加压物品（香水、古龙水、指甲油、喷雾罐、打火机、暖宝宝）
- 单独包装的电池和充电宝
- 酒类、烟草和电子烟
- 新鲜或易腐食品、肉类、植物和种子
- 武器、仿制武器和防身喷雾；假冒商品
- 药品和保健品（通常受限制；可能需要 FDA 批准）
- 防晒霜及其他受监管、可能有额外进口要求的化妆品或药品
- 现金、礼品卡和贵金属

完整详情请参阅[禁运与限运物品](https://koreahaul.com/shipping-info/restricted)页面。
