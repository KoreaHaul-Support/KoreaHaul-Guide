从韩国商店到您家门口只需三步。

1. **创建账户。** 您会获得一个专属的 Postbox code（个人邮箱代码），例如 `KF2331`，以及我们位于仁川的仓库地址。注册时还会发放一张 ₩5,000 的欢迎优惠券（Welcome Coupon）。
2. **把商品送到我们的仓库。** 您可以通过 Buy For Me 让我们代您购买，也可以自己购物后通过 Receive For Me 寄到我们这里。
3. **寄回家。** 将所有商品合并到一个箱子里，选择承运商并付款。

## 您的 Postbox code

我们通过 Postbox code 将包裹与您匹配。它由两个字母和四个数字组成，例如 `KF2331`。注册后它会立即显示在您的个人主页上，并且永远不会改变。

> 向我们的仓库寄送任何物品时，请务必附上您的 Postbox code。

## 您的韩国地址

当韩国商店询问收货地址时，请完全按照下面的内容填写。收件人请填写**您本人的姓名**，而不是 "KoreaHaul"。

```text
收件人：[您的姓名]
인천광역시 부평구 부평북로 58, 2층 201호 [您的 Postbox code]
58, Bupyeongbuk-ro, Bupyeong-gu, Incheon
2F, Suite # 201 [您的 Postbox code]
邮编 21302
Republic of Korea
电话：010-5725-1222
```

韩国网站的结账表单通常要求填写韩文地址。

- **地址搜索（주소 찾기）：** 搜索 `인천광역시 부평구 부평북로 58`。表单会自动为您填入邮编（우편번호）。
- **详细地址（상세주소）：** `2층 201호 [您的 Postbox code]`

> 没有 Postbox code，我们就无法将包裹与您的账户匹配，从而导致延误。我们会将其作为无人认领包裹保管，并列在我们的[公告页面](https://koreahaul.com/support/notice)上，请前往查看并认领。

## 包裹到达后会发生什么

- 包裹到达仓库后，我们通常会在 1-2 天内完成入库。
- 我们会拍摄开箱照片/视频并上传到您的个人主页，供您查看。
- 包裹会连同入库日期一起显示在您的仓库列表中。
- 45 天免费仓储期从该入库日期开始计算。

不同日期入库的物品分别单独计算天数。

## 准备寄出

- 在 [Ship For Me](https://koreahaul.com/account/ship-for-me) 申请寄送。
- 我们会打包、称重并测量箱子尺寸。
- 根据我们报出的实际价格选择承运商。
- 申请前可使用 [KoreaHaul](https://koreahaul.com/) 上的运费计算器（Shipping Calculator）预估费用。
