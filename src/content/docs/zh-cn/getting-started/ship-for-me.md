我们将您仓库中的所有物品打包成一批货件，寄往您的国家。

## 运作方式

1. 从您的[仓库存储](https://koreahaul.com/account/warehouse-storage)中选择要寄送的物品。
2. 为每件物品选择处理选项，并为这批货件选择包装选项。
3. 确认您的收货地址和申报价值。
4. 我们会打包、称重并测量箱子尺寸，然后将各承运商的价格发送给您。
5. 选择承运商并付款，然后获取您的追踪号码。

## 处理选项

按物品或按包裹选择。

| 选项 | 价格 | 备注 |
| --- | --- | --- |
| Inclusions Basic（专辑附赠品基础） | ₩1,000 / 件 | 仅限购买的专辑。仅限小卡和预购特典（POB）。 |
| Inclusions Premium（专辑附赠品高级） | ₩2,000 / 件 | 仅限购买的专辑。可精确选择保留哪些附赠品。 |
| Extra Protection（额外保护） | ₩3,000 / 件 | 额外的气泡膜和缓冲材料。 |
| Vacuum Packing（真空压缩包装） | ₩6,000 / 件 | 仅在尺寸允许时提供。压缩衣物和床上用品，以降低计费重量。 |

## 包装选项

按批货件选择。

| 选项 | 价格 | 备注 |
| --- | --- | --- |
| Optimized Pack（优化包装） | ₩2,000 + ₩1,000 / 包裹 | 我们重新包装以减少体积和费用。包含基础保护和打包前照片/视频。可能会移除原始快递箱，但绝不拆除密封包装。 |
| Remove Original Box（移除原包装箱） | ₩3,000 + ₩2,000 / 包裹 | 重新包装时丢弃原始零售包装盒或快递箱。**目前暂不提供。** |
| Priority Pack（优先打包） | ₩5,000 / 批货件 | 您的货件将在 24 小时内完成打包并准备寄出。 |
| Package Split（包裹拆分） | ₩5,000 / 拆分包裹 | 将存放在您仓库中的物品分成多个寄出包裹。 |
| Adult Signature Required（成人签收） | ₩6,000 | 派送时须由成年人签收。仅限 FedEx。 |
| Shipping Insurance（运输保险） | 申报价值的 2% | 承保运输途中的丢失或损坏。适用于 FedEx 及部分 Standard Shipping 目的地。 |

## 须知

- 只要承运商的尺寸和重量规定允许，所有物品都会装进一个箱子。
- 标准打包最多需要 2 个工作日。
- 承运商按实际重量和体积重量中较高者计费。Optimized Pack 和 Vacuum Packing 通常可以降低计费重量。

## 配送限制

- 我们无法配送至邮政信箱（PO box）或军事地址（APO、FPO、DPO）。
- 通常无法配送至欧盟境内的岛屿。
- 如果承运商将您的地址归类为偏远地区，则需支付偏远地区附加费。我们会将附加费计入您的运费报价中。

我们正在努力扩大服务范围。如果您住在偏远地区，请在申请我们的服务前先联系我们。
