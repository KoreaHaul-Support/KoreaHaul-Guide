所有价格均以韩元（KRW）计。

您需要付款两次：先支付购买费用，再支付国际运费。将以下各项相加，即可估算订单从店铺到您家门口的总费用。

## 第 1 步：购买账单（Buy For Me）

| 项目 | 需加上的费用 |
| --- | --- |
| 商品价格 | 韩国店铺上标示的价格。 |
| 韩国国内运费 | 店铺将商品寄到我们仓库收取的运费。满一定金额通常免运费。 |
| Buy For Me 服务费 | Basic ₩2,000 或 Standard ₩5,000，按商品种类收费。Premium 每件 ₩30,000。 |

<div class="kh-callout kh-callout--caution">

<p class="kh-callout-title">上线优惠</p>

在 2026年12月31日前提交的请求，Basic 和 Standard 均为 **₩0**。Premium 不参与此优惠。

</div>

使用 Receive For Me？您自行购买商品，因此可以跳过这一步。

## 第 2 步：运费账单（Ship For Me）

### 1. 确定计费重量

承运商按以下两者中较高者收费：

- **实际重量** - 包裹在秤上的重量。
- **体积重量** - L × W × H (cm) ÷ 5000。

例如，一个 40 × 30 × 25 cm、重 3 kg 的箱子，体积重量为 6 kg，因此按 6 kg 收费。

### 2. 查询运费

在 [KoreaHaul](https://koreahaul.com/) 的运费计算器中输入您的国家和计费重量。如适用，进口费用和偏远地区附加费将另行收取。可在[承运商与运费](/shipping/carriers-and-rates/)中比较各承运商。

### 3. 加上所需的选项

| 选项 | 价格 |
| --- | --- |
| Inclusions Basic / Inclusions Premium | ₩1,000 / ₩2,000 每件 |
| Extra Protection（额外保护） | ₩3,000 每件 |
| Vacuum Packing（真空压缩包装） | ₩6,000 每件 |
| Optimized Pack（优化包装） | ₩2,000 + ₩1,000 / 包裹。含打包前照片或视频。 |
| Priority Pack（优先打包） | ₩5,000 / 批货件 |
| Package Split（包裹拆分） | ₩5,000 / 拆分包裹 |
| Adult Signature Required（成人签收） | ₩6,000 |
| Shipping Insurance（运输保险） | 申报价值的 2% |

所有选项均为可选。各选项包含的内容请查看[费用](/getting-started/fees/)。

### 4. 如有需要，加上仓储费

前 45 天免费。之后每个包裹每天 ₩1,000；体积重量达到 10 kg 或以上时，每天 ₩2,000。仓储费作为 Additional Charge 显示在您的运费账单上。

### 5. 加上进口费用

- **DDP：** 您在结账时支付关税、税费和清关费。
    - International Standard Shipping：清关费 ₩2,000 至 ₩5,000
    - FedEx International Connect Plus：清关费 ₩6,000，如预估进口费用超过 ₩120,000，则为 ₩12,000
- **DAP：** 包裹到达时，所有适用的关税、税费和清关费需支付给承运商或海关。

关税取决于您所在国家的免税额度、申报价值和 HS code。请查看[关税与税费计算](/shipping/duty-and-tax-calculation/)，以及[国家/地区指南](/country-guide/)中您所在国家的页面。

## 第 3 步：付款手续费

两张账单在结账时都会加收手续费，金额取决于您的付款方式。Wise 的手续费通常最低。请查看[付款方式](/getting-started/payment-methods/)。

根据付款方式，可能会有金额限制。

## 示例

- **商品：** 一张专辑 ₩22,000，一支应援棒 ₩45,000
- **店铺：** 两家不同的店铺，Basic Proxy
- **到货：** 2 个包裹到达我们的仓库
- **承运商：** FedEx International Connect Plus
- **箱子：** 30 × 25 × 20 cm，秤重 1.2 kg
- **体积重量：** 30 × 25 × 20 ÷ 5000 = 3 kg
- **计费重量：** 3 kg

| 项目 | 金额 |
| --- | --- |
| 商品（专辑 ₩22,000 + 应援棒 ₩45,000） | ₩67,000 |
| 韩国国内运费（2 家店铺 × ₩3,000） | ₩6,000 |
| Buy For Me 服务费（Basic，上线优惠） | ₩0 |
| **购买账单** | **₩73,000**，另加付款手续费 |
| 运费，3 kg（示例费率） | ₩50,000 |
| Inclusions Basic（1 张专辑） | ₩1,000 |
| Optimized Pack（2 个包裹：₩2,000 + 2 × ₩1,000） | ₩4,000 |
| 清关费 | DDP：₩6,000 / DAP：₩0 |
| 关税和税费 | 视您所在国家而定 |
| **运费账单（DDP）** | **₩61,000**，另加关税、税费和付款手续费 |
| **运费账单（DAP）** | **₩55,000**，另加付款手续费。关税、税费和清关费在到货时支付。 |

<div class="kh-callout kh-callout--note">

本示例中的运费仅供参考。请使用运费计算器查询您的实际运费。

</div>

## 您的实际报价

您的商品到达我们仓库后，我们会称重并测量尺寸，然后向您发送报价，将所有可用承运商并列比较。运费报价的有效期为 **5 天**。

## 省钱小贴士

- 将所有商品合并为一批货件寄出。
- 使用 Optimized Pack 或 Vacuum Packing 来减少体积重量。
- 在 45 天免费仓储期结束前寄出。
- 在可以使用 Wise 的地区，用 Wise 付款。

更多小贴士请查看[如何节省运费](/shopping-tips/how-to-spend-less-on-shipping/)。
